# DevNexus Digital — Site Regional Premium

Versão actualizada do site institucional.

## Alterações

- presença regional destacada: Guiné-Bissau, Angola, Cabo Verde e São Tomé e Príncipe;
- nova secção de presença regional;
- comunicação institucional reforçada;
- rodapé com âmbito de actuação;
- paleta visual mais viva e sofisticada;
- formulário removido, mantendo contactos directos por email;
- configuração para `devnexusdigital.com`.

## Publicação

Substituir o conteúdo do repositório do site pelos ficheiros deste pacote e efectuar commit/push.

## Correcção do cubo

Foi reposto o motor JavaScript do cubo 3D animado no `index.html`. O formulário continua removido.

## Cubo interactivo

O cubo deixou de ser apenas decorativo. Cada quadrado visível aceita gestos de arrastar para rodar a fila ou coluna correspondente. Também inclui mudança de vista, mistura, reposição e rotação automática.
